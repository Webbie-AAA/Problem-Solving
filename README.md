# Daily Python Practice

A collection of daily exercises focused on improving problem-solving skills and practicing Test-Driven Development (TDD) in Python.

## Structure

Each exercise is stored in its own folder and contains:

readme.md — problem description, examples, and approach
main.py — implementation
test.py — tests validating expected behavior

## Running Tests

pytest

## Goals

1. Write clean, testable code
2. Strengthen algorithmic thinking
3. Build consistency through daily practice
